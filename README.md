# 🚀 Cinereus Techserv Pvt Ltd — Corporate Website

Modern enterprise website built for **Cinereus Techserv Pvt Ltd**, showcasing technology solutions across:

- 🏨 Hospitality
- 🎓 Smart Classrooms & Education
- 🖥️ Data Centers & Enterprise Networking
- 🔬 Digital Forensics
- 🏢 Building Automation

Designed with a modern UI, responsive architecture, smooth animations, and scalable component-driven development using the latest Next.js ecosystem.

# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/your-username/cinereusfe.git
```

---

## Install Dependencies

```bash
npm install
```

---

## Run Development Server

```bash
npm run dev
```

---

## Build for Production

```bash
npm run build
```

---

## Start Production Server

```bash
npm run start
```
